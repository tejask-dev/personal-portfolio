---
name: design-loop
description: Polish Open Water against its existing design system using desktop and phone screenshots, one evidenced correction per round.
---

Read `design/TASTE.md`, `design/tokens.css` and `design/references/README.md`.
Preserve content, routes, motion preferences and input ownership.

1. Capture the real chooser, reading hero, work and contact at 1440x900 and
   390x844. Wait for fonts, decoded visible images and completed entrance motion.
   Capture the chooser viewport, not a full-page image of the document behind it.
2. Open the images. Score Type, Rhythm, Density, Restraint, Alignment and Focus
   from 1–5, with one concrete piece of visual evidence for each score.
3. Fix only the weakest category, using the existing tokens; state the change.
4. Capture again. Revert ineffective changes. Stop at all scores >=4 or five rounds.
5. Check 320px, short landscape, keyboard focus, actual link hit-testing and
   navigation. Run existing entry/boarding/descent tests for affected surfaces.
6. Record commands, results and limitations in `design/REVIEW.md`. Visual scores
   are judgments; do not present them as universal quality or performance measures.

Do not install global tools, change public claims or add product features to polish.
