# References and scope

The user supplied the current chooser, yacht and portfolio screenshots and the
Claude Design Stack workflow. They anchor the existing ocean/editorial identity.

- [Impeccable](https://github.com/pbakaus/impeccable): polish and motion guidance,
  read directly; no launcher or global plugin installation.
- [Taste](https://github.com/Leonxlnx/taste-skill): existing-brand/redesign workflow,
  preserve the stack, type and palette; record before/after and test real paths.
- [Awesome Design MD — Apple](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md):
  third-party analysis used for restraint, hierarchy and consistent action states.
  Its numerical claims are not independently measured Apple specifications.
- Playwright: the already-installed library captures real Chrome viewports and
  checks links, keyboard access, overflow and axe. No additional MCP installation.
- [img2threejs](https://github.com/img2threejs/img2threejs) was evaluated but not
  invoked: this pass has no new 3D object, and the user requested replacing the
  procedural diver with film. No Figma frame was provided, so no Figma calls.

## Project rules extracted from the running site

Source-confirmed: ivory #f6f1e7, ink #143b43, muted #42636a, 1280px content grid,
48/32/20px responsive gutters, local Spectral and Aspekta font assets. Proposals:
400-weight body text, a shared chooser font family, and a 68ch lead measure.
These are portfolio decisions, not inferred measurements of an external brand.

Keep: editorial serif titles, the illustrated boat, real work evidence, and the
optional cinematic ocean. Avoid: generic purple gradient heroes, shadowed feature
cards, unsupported marketing claims, and repeated animation in reading sections.
Do not copy Apple's fonts, blue accent, product tiles or branded imagery.

`../variants/` holds five unshipped structural studies using the existing copy.
The type-led study preserves the reading route; the chooser keeps its purposeful
split art and two distinct paths. Browser evidence paths are in `../REVIEW.md`.
