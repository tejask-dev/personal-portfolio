# Open Water — the scrolling descent

The limestone terraces, arch, coral, human diver, fish, water, light shafts and
fallback SVG are original procedural artwork created for this portfolio with
Codex assistance. They use no downloaded models, textures or copied demo art.
The editable source is in `client/src/features/scroll-dive/`.

Native document scrolling is observed using the installed Motion React package.
Motion is by Motion B.V., licensed under MIT; its exact installed notice is
included in [MOTION-LICENSE.md](./MOTION-LICENSE.md).
Three.js and React Three Fiber remain the existing rendering stack.

Research references: [Motion](https://github.com/motiondivision/motion),
[Lenis](https://github.com/darkroomengineering/lenis),
[Drei](https://github.com/pmndrs/drei),
[React Spring](https://github.com/pmndrs/react-spring),
[Scrollama](https://github.com/russellsamora/scrollama), and
[SplitType](https://github.com/lukePeavey/SplitType).
These informed the use of native scrolling, bounded progress, semantic chapters
and restrained word reveals. No source from their example applications was
copied. Only Motion from that list is used by the new scroll controller; the
other references do not add dependencies.

Depth readings are fictional scene coordinates. The portfolio, all links and
all chapter copy remain available without the animated illustration.
