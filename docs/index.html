Small builds / concrete decisions

On the workbench.

Two projects that show how I think about boundaries.

Authorization prototype / public code

RelayPass

A delegated agent should receive only the permission it needs. RelayPass explores signed permissions that narrow as work passes between agents, with deterministic checks before disclosure or action.

Revoking a parent permission also invalidates its descendants. That boundary is enforced in code, rather than left to a model’s interpretation.

Built with Claude. The Passport adapter, travel agents, downstream services and purchases are simulated; this is not a live merchant integration.

Inspect the prototype and its limits ↗

Open Water

A portfolio has two different jobs: make the work easy to read, and give someone a reason to explore. Here, the reading pages remain useful without graphics or JavaScript.
